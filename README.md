# Slingshot Siege

My entry for js13k 2026 and a web re-creation of the [*Bob-omb Squad* minigame](https://www.mariowiki.com/Bob-omb_Squad) from New Super Mario Bros.

## Credits
* Game engine powered by [js13k-ecs](https://github.com/kutuluk/js13k-ecs)
* Character vectors designed with [Inkscape](https://www.inkscape.org/)
* Sound effects made with [ZzFX](https://killedbyapixel.github.io/ZzFX/)
* Background music: duets no. 5 and 10 from Luigi Hugues' *La Scuola del Flauto*, made with [ZzFXM](https://github.com/keithclark/ZzFXM)
